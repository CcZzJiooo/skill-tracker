# 我用纯前端做了一个“抓包” AI Agent 的神器，Cursor 和 Claude 到底瞒着我们干了啥？

你是否有过这种疑惑：
在使用 Cursor、Claude Code、Windsurf 等 AI 助手编程时，后台终端呼啦呼啦闪过一堆日志，AI 似乎在默默读取各种文件和“技能（SKILL.md）”，但你根本不知道它到底读了什么、有没有读错、是不是在反复读取同一个技能浪费 Token？

AI 越智能，它的调用过程就越像一个“黑盒”。

为了打破这个黑盒，我开源了一个本地优先的可观测性小工具：**Skill Tracker**。

## 💡 它是干什么的？

**Skill Tracker** 专门用来“抓包”和“治理”你本地 AI Agent 的技能调用。它不需要后端，不上传任何日志，100% 本地运行，完全保护隐私。

你只需要双击运行，它就会：
1. **自动扫描本地日志**：自动兼容扫描 Antigravity, Claude Code, Cursor, Windsurf, Codex 等主流 AI 助手的后台会话日志（支持零配置自动探测项目技能！）。
2. **技能热力图与时间线**：把 AI 什么时候调用了什么技能，用最直观的热力图和时间线画出来。
3. **中文技能字典**：将复杂的英文技能描述，统一在本地翻译和管理为中文说明，方便快速理解。
4. **技能重叠度与治理检测**：一键扫出本地哪些技能功能重叠、哪些说明缺失、哪些在浪费 Token，并直接生成治理方案。
5. **GitHub 搜索雷达**：可以直接按中文意图在 Dashboard 里搜索 GitHub 开源技能库！

## 🚀 这一次，我们做到了“真正的一步到位，开箱即用”！

在此前的版本中，有些用户反馈初次克隆项目时，由于系统还没有配置全局技能文件夹，会导致采集脚本报错。

在最新的版本中，我们彻底做到了**零配置冷启动**：
- **项目技能自动识别**：即使你是 AI 编程新手，没有全局技能，脚本也会自动识别当前项目内的本地 `.agents/skills` 或 `.cursor/skills` 目录！
- **自动 Fallback 静态预览**：如果你的系统限制了 PowerShell 脚本的运行权限，运行 `run.bat` 将会自动降级直接拉起静态 HTML，依然能无缝查看 Demo 数据！

## 🛠️ 如何开始？

1. **下载或克隆项目**：
   ```powershell
   git clone https://github.com/CcZzJiooo/skill-tracker.git
   cd skill-tracker
   ```
2. **Windows 用户**：双击运行 `启动看板.vbs`（或 `run.bat` 作为备选），看板会在你的默认浏览器中自动打开！
3. **数据隐私**：所有采集到的数据均以本地 `.js`/`.json` 文件的形式保存在 `dashboard/` 目录下，并已自动加入 `.gitignore`。支持一键导出**匿名化报告**，安全无忧！
